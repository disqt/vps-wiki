# Plugins

Les serveurs PaperMC sont compatibles avec les plugins Paper, Spigot, et Bukkit.

Il contient actuellement les plugins suivant :&#x20;

| Plugin                      | Description                                                                                           |
| --------------------------- | ----------------------------------------------------------------------------------------------------- |
| AuthMe                      | Gère les mots de passe des utilisateurs                                                               |
| BlueMap                     | Génère une carte en 3D visionnable via navigateur                                                     |
| BlueMapOfflinePlayerMarkers | Affiche sur BlueMap l'icône des joueurs à l'endroit où ils se sont déconnectés                        |
| DHSupport                   | Active le server-side rendering pour Distant Horizons                                                 |
| Multiverse-Core             | Permet de gérer plusieurs mondes sur le serveur                                                       |
| PlugmanX                    | Permet d'installer, activer, désactiver des plugins sans avoir à redémarrer le serveur                |
| WorldEdit                   | Permet de copier coller des blueprints et de manipuler la carte en jeu                                |
| AxGraves                    | Fait spawn une pierre tombale lorsqu'un joueur meurt, avec son stuff et une partie de son XP          |
| BlueMapDeathMarkers         | Affiche un marqueur sur BlueMap pendant 5min à l'emplacement où un joueur est mort en jeu             |
| BlueMapSkinIntegration      | Utilise le skin des joueurs pour créer leurs icônes sur BlueMap                                       |
| LuckPerms                   | Gère les différentes permissions sur le serveur, (par exemple admin vs membre)                        |
| Multiverse-Inventories      | Permet de partager un inventaire entre le nether, l'end et l'overworld                                |
| SkinsRestorer               | Permet d'avoir accès à son skin mojang ou un skin personnalisé même si le serveur est en mode offline |
| BlueMap-BannerMarker        | Affiche les bannières nommées sur BlueMap                                                             |
| BlueMapMCMapSync            | Syncronise la carte BlueMap avec les cartes en jeu                                                    |
| Chunky                      | Permet de pré-générer les chunks pour éviter des lags du serveur pendant l'exploration                |
| MiniMOTD                    | Permet d'afficher de manière aléatoire des mots personnalisés comme description de serveur            |
| Multiverse-NetherPortals    | Permet de lier des dimensions du nether avec des dimensions de l'overworld                            |
| spark                       | Profiler qui permet de visualiser les performances du serveur                                         |
