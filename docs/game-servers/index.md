# Game Servers

The VPS hosts three game servers, each running under its own dedicated Linux user.

## Connection Details

| Game | Address | Port |
|------|---------|------|
| Counter-Strike 2 | `disqt.com` | 27015 |
| Minecraft | `disqt.com` | 25565 (default) |
| Xonotic | `disqt.com` | 26420 |

## Server Pages

- [CS2 Dedicated Server](cs2.md) -- Counter-Strike 2 with custom plugins, modes, and bot management
- [Minecraft Server](minecraft.md) -- PaperMC with AuthMe, BlueMap, and automated backups
- [Xonotic Server](xonotic.md) -- Deathmatch with grappling hook, managed by LinuxGSM
